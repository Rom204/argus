Columns

TIME
When the kernel saw the event, shown in your local time.
TYPE
Which kernel hook fired — see event types below.
PID
Process ID, the same number ps shows.
PPID
PID of the parent — the process that started this one.
UID
Real user ID. 0 is root. On SETUID and CAPS rows it is the value after the change.
COMM
The kernel's short name for the process (max 15 characters, not a full path). A name in parentheses, like (fwupdmgr), is a service systemd has forked but not yet exec'd.
CAPS
Effective capabilities — the root powers actually in force — as a hex bitmask. 0x0 is none; 0x1ffffffffff is all 41, i.e. full root.

Event types

EXECVE
A process started running a new program.
EXIT
A process ended.
SETUID
A process changed its user or group identity.
CAPS
A process's credentials changed — covers capset() and capabilities a binary gains at exec, which SETUID does not report.
